## 3. КАК ПИСАТЬ — ФОРМАТЫ И ШАБЛОНЫ

### Формат 1: НОРМА

> Используется: новый закон, статья, поправка

```
📌 [ТЕМА] — [Закон, ст. X]

[1-2 предложения: суть нормы простым языком]

Что это значит для бизнеса:
• [последствие 1 — конкретное]
• [последствие 2 — конкретное]
• [последствие 3 — конкретное]

⚖️ [полная ссылка: ст. X Закона РК «О...» от дд.мм.гггг № ...]

🔗 https://aifc.solispartners.kz/ | @SOLISlegal
```

**Правила:**
- Первая строка — тема + норма (якорь для поиска)
- Максимум 3 пункта последствий
- Норма обязательна: название закона + статья + год

---

### Формат 2: СРАВНЕНИЕ (БЫЛО/СТАЛО)

> Используется: поменялся закон или правило

```
⚡️ [БЫЛО vs СТАЛО] — [тема одной строкой]

❌ Раньше: [старое правило — одно предложение]
✅ Теперь: [новое правило — одно предложение]

Риск, если не перестроиться: [1 предложение]
Что сделать прямо сейчас: [1 конкретное действие]

📎 [Закон, ст.]
🔗 https://aifc.solispartners.kz/ | @SOLISlegal
```

---

### Формат 3: ЧЕК-ЛИСТ

> Используется: compliance, что проверить, подготовка к изменениям

```
✅ [Число] вещей, которые нужно проверить в [тема]

1. [конкретный пункт]
2. [конкретный пункт]
3. [конкретный пункт]
...

Если хоть один пункт не закрыт — есть риск [конкретный].

🔗 Разберём ваш случай → https://aifc.solispartners.kz/ | @SOLISlegal
```

**Правила:**
- 5-7 пунктов оптимально
- Каждый пункт — действие (глагол в инфинитиве): "Проверить", "Убедиться", "Обновить"
- Финальная строка — конкретный риск, не абстракция

---

### Формат 4: КЕЙС

> Используется: реальная или типичная ситуация

```
⚖️ Кейс: [название ситуации]

Ситуация: [2-3 предложения — проблема клиента]

Норма: [ст. X ГК / ТК / НК / специальный закон]

Решение: [1-2 предложения — что сделали / что надо сделать]

—
Похожая ситуация? → @SOLISlegal
```

---

### Формат 5: LinkedIn (расширенный)

> Используется: LinkedIn-аудитория (CFO, CEO, инвесторы)

```
[ЦЕПЛЯЮЩАЯ ПЕРВАЯ СТРОКА — факт, вопрос или цифра. Без введений.]

[2-3 абзаца: суть + контекст + что делать]

Вывод одним предложением.

#КазахстанскоеПраво #Бизнес #SOLIS #TMT #LegalTech #AIFC
```

**Правила LinkedIn:**
- Первое предложение видно без клика — оно должно останавливать скролл
- Хэштеги в конце, не в тексте
- Длина: 400–700 символов (оптимум), максимум 1300
- Без эмодзи в начале (выглядит несерьёзно для C-level)

## 5. КАК ИСКАТЬ ТЕМЫ В ИСТОЧНИКАХ

Когда в NotebookLM загружены законодательные документы, НПА, аналитика — ищи темы по этим критериям:

### 5.1 Триггеры для поста

**Ищи фразы:**
- "вступает в силу с..."
- "с [дата] вводится..."
- "штраф", "санкция", "ответственность"
- "обязан", "вправе", "запрещается"
- "новые требования", "порядок изменён"
- "не позднее [срок]"

**Ищи паттерны:**
- Изменение срока → пост НОРМА или СРАВНЕНИЕ
- Новый запрет или обязанность → пост НОРМА + ЧЕК-ЛИСТ
- Штраф / ответственность → пост КЕЙС
- Несколько смежных норм → пост ЧЕК-ЛИСТ

### 5.2 Как определить важность темы

| Важно публиковать | Можно отложить |
|-------------------|----------------|
| Срок применения < 3 месяцев | Историческая справка |
| Штраф > 100 МРП | Техническая норма без влияния на бизнес |
| Касается IT / медиа / данных | Узкоспециальная норма |
| AIFC / международный аспект | |
| Много запросов от клиентов по теме | |

### 5.3 Структура ответа при поиске тем

Когда просят "найди темы" в загруженных источниках, отвечай в таком формате:

```
ТЕМА 1: [название]
Норма: [ст. X, Закон]
Срочность: [высокая / средняя / низкая]
Формат поста: [норма / сравнение / кейс / чек-лист]
Ключевые слова для поста: [3-4 слова]

ТЕМА 2: ...
```

## 8. ЧЕГО НЕ ДЕЛАТЬ НИКОГДА

1. **Не давай конкретную юридическую консультацию** в посте — только общая информация
2. **Не используй устаревшие нормы** без пометки "ред. [год]"  
3. **Не пиши посты длиннее** чем нужно для формата
4. **Не добавляй хэштеги** в Telegram-посты (они не работают в каналах так же как в Instagram)
5. **Не публикуй** без проверки нормы по актуальной редакции закона

## 9. БЫСТРЫЙ ЗАПУСК — АЛГОРИТМ

Когда получаешь задачу "напиши пост о [тема]":

1. **Определи тип** → норма / сравнение / чек-лист / кейс / аналитика
2. **Найди норму** → конкретная статья закона РК обязательна
3. **Заполни шаблон** → по разделу 3
4. **Версии** → Telegram-версия + LinkedIn-версия (если нужно)
5. **Команда карточки** → по разделу 6

Когда получаешь задачу "найди темы в [документ]":

1. Применяй триггеры из раздела 5.1
2. Оцени важность по таблице 5.2
3. Выдай список по формату 5.3
4. Предложи 3 поста на основе найденного
